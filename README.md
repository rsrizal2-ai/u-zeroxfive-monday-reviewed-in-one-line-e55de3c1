# Monday, Reviewed in One Line

A [make.fun](https://make.fun/bounty/u-zeroxfive-monday-reviewed-in-one-line-e55de3c1) entry: the funniest one-line review of my own Monday, under 200 characters, nothing else.

`main.ts` writes the line to `/output/entry.txt` and validates it against the gate (1 to 200 characters, not only white space) before and after writing.

Run it with Node 22.18 or later:

```sh
node main.ts
```
